## 📌 About

**Programming-Languages** is one central place for my code across every language I work with. Each language lives in its own folder with its own README, and the programs inside are ordered so that they build on one another — the earliest files assume nothing, and later ones layer on new features as you go.

The idea is simple: instead of scattered snippets, this repo gives a beginner a readable path through a language. Read the files in order and you're effectively walking through the language's features one at a time.

Different languages here serve different purposes:

- **C** — the foundation. Basics, fundamentals, and core programming logic.
- **C++** — competitive programming and object-oriented work.
- **Java** — object-oriented programming in depth.
- **Others** — each added with its own focus as I learn and use them.

## 👥 Who This Is For

- **Complete beginners** who want a readable, ordered path into a language rather than scattered tutorials.
- **Students** revising fundamentals before an exam or lab.
- **Anyone switching languages** who wants to see familiar concepts expressed in unfamiliar syntax.

No prior setup knowledge is assumed. If you can open a file and run a compiler, you can use this repo.

## 🖥️ How to Use

Clone the repository:

```bash
git clone https://github.com/Md-Manam-Khan/Programming-Languages.git
cd Programming-Languages
```

Then:

1. **Pick a language folder** based on what you want to learn.
2. **Read that folder's README** first — it explains how the files are ordered.
3. **Go through the files in order.** Each one introduces something new while reusing what came before.
4. **Run them, break them, change them.** Reading code teaches less than editing it and seeing what happens.
