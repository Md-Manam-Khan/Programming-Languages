## 📌 What This Folder Covers

This is the most complete section here, and it's built as a ground-up path through the language. Starting from a first program that does nothing but print, the files move step by step through:

- Input, output, and variables
- Operators and expressions
- Conditional logic and decision making
- Loops and pattern building
- Number theory and digit manipulation
- Arrays and array algorithms
- Searching and sorting
- Matrices and two-dimensional data
- Strings and character handling
- Functions, parameters, and return values
- Recursion
- Pointers and pointer arithmetic
- Structures
- File handling
- Dynamic memory allocation

Each topic builds directly on the last. Nothing appears before the concepts it depends on.

216 programs in total, numbered `000` through `215`.

## 🔢 How the Files Are Ordered

Every file is prefixed with a three-digit number:

```text
000_...
001_...
002_...
```

**That number is the learning order — not a difficulty rating.** Read from the lowest number upward and you'll encounter each feature of the language roughly when you're ready for it. Jumping into the middle is fine if you already know the basics, but the numbering exists so beginners never have to guess what comes next.

Filenames describe what the program does, so you can also scan the folder to find a specific topic.

## 🖥️ Running the Code

You'll need a C compiler (GCC is the common choice). To compile and run any file:

```bash
gcc filename.c -o program
./program
```

On Windows:

```bash
gcc filename.c -o program.exe
program.exe
```

---

## 🎯 How to Get the Most Out of It

1. **Read before you run.** Try to predict what the output will be.
2. **Then run it** and see whether you were right.
3. **Change something and break it.** Modify a condition, shift a loop boundary, remove a line. The error messages teach as much as the working code.
4. **Rewrite it from memory** a day later. That's the step most people skip, and it's the one that makes it stick.

## 💡 A Note for Beginners

If a file confuses you, the answer is usually in an earlier-numbered one. Go back, not forward — C rewards patience with the basics far more than it rewards rushing ahead.
